## Featured Projects

The portfolio currently features several projects spanning machine learning, statistics, sports analytics, exploratory data analysis, and artificial intelligence.

### MLB Postseason Prediction - Undergraduate Honors Thesis

An undergraduate research thesis investigating statistical and machine learning approaches for predicting MLB postseason outcomes.

### World Cup Predictor

A machine learning project focused on predicting FIFA World Cup match outcomes using historical international soccer data.

### NFL Officiating EDA

An exploratory data analysis project examining patterns and trends in NFL officiating data.

### Ecommerce Graph Analytics

A graph analytics project analyzing relationships within an e-commerce network to identify structural patterns and meaningful connections.

### AI Consistency Experiment

An experimental study investigating whether consistency-focused prompting instructions affect the consistency of responses generated by large language models across repeated generations.
